A collection of Python coursework projects organized by week. Each folder contains a separate assignment or practice project, ranging from beginner console programs to games, GUI apps, API/email automation, and browser automation.

This repository is a learning archive rather than one single application.

## Project Highlights

- Week 1: beginner Python console programs and ASCII-art based exercises

- Week 3: Pong, turtle crossing game, and file/data practice
- Week 4: Tkinter flash-card app, Tkinter quiz UI, and API/environment-variable practice
- Week 5: projects using requirements files, OAuth/setup helpers, and browser automation

## How To Run A Project

Open the folder for the project you want to run, then execute its `main.py` file:

```bash
cd python_projects/week_2/project_03
python main.py
```

Some projects include a `requirements.txt`. For those projects, install dependencies first:

```bash
pip install -r requirements.txt
```

Some later projects also include `.env.example` files. Copy the example to `.env` and fill in the required keys before running.

## Notes

- These are school exercises, so each project is intentionally scoped to the lesson being practiced.
- Some games use Python's `turtle` or `tkinter`, so they need a local desktop Python environment.
- API and automation projects may require external credentials or browser drivers.
- Each week folder may include its own README with more specific assignment notes.
